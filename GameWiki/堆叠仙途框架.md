# 堆叠仙途

## 一、重构宗旨

### 1. 沿用原作

- **卡牌堆叠交互**
  - "物理化"的堆叠，把抽象生产关系变成了符合直觉的动作
  - 即时的因果反馈会带来较强的掌控感和探索欲
- **发现/探索配方**
  - 通过不同卡牌堆叠产生新结果，从而产生惊喜感和成就感
  - 构成前中期的核心驱动力
- **从手动到自动**
  - 前期手动强化参与感，中期将重复互动行为过渡成"自动化"生产
  - 减少重复操作带来的疲劳感
- **高自由度**
  - 没有强线性任务，只提供了轻度短期和长期目标。玩家可以自由决定发展方向
  - 是"去何方由你决定"的沙盒感重要的构成因素

### 2. 优化原作

- **中后期节奏断裂**
  - 新手阶段：配方产出机制（抽干卡池），让抽不同卡池的行为增加了额外价值观权重，干扰用户的选择
  - 中期：随机抽卡带来的疲惫感。即为了特定稀有卡牌，迫使玩家长时间、无技术含量的重复抽固定卡池，新鲜感迅速丧失
- **卡牌管理的繁琐**
  - 中后期阶段，寻找/管理桌面上大量卡牌（大量时间被迫手动分类、整理等）
  - 这种"桌面清理"工作打断心流（行为与核心成长决策无关联）
- **自动化与村民AI的局限性**
  - 半自动生产线、村民AI抵消决策，逼迫玩家频繁手动干预
  - 消解了"自动化"阶段带来的成就感
- **随机的过度惩罚**
  - 卡包产出机制，在用户明确发展路线时会产生无力感
- **臃肿的食物配方**
  - 食物类型、配方品类杂多，但回收侧只关注食物的数量和点数，属于冗余设计
- **性价比较低的高阶建筑物**
  - 中后期出现很多配方复杂的后期建筑，建筑物的培养深度与建筑物效果和主线生存目标不 match
- **复杂的战斗系统**
  - 战斗系统（兵种、克制链、BUFF）在前端显示简化为"堆叠比大小"，体感缺乏策略深度，感受单调，降低装备培养、人员培养的欲望
  - 其次，战斗系统复杂程度高，成长阶段节奏就要压缩，深度降低，最后由战斗释放。成长策略和战斗释放需要明确主从关系
- **Rougelike 沙盒思路结构重构**
  - 包含单局时长、不同的策略分支带来的变化、单局操作频率等，需要根据 RougeLike 结构改造
- **手机端弱化操作**
  - 包含动物、怪物卡牌自动移动，桌面卡牌总量（单屏可视有效信息）、操作频次，根据移动端特性做删减优化
- **单局周期过长**
  - 当前偏"沙盒"定位，改成移动端 RougeLike 思路，单局节奏要加快，正反馈爆发时点更短

## 二、功能结构 & 数值框架

> **世界观概述**：玩家是修真世界的修士。通过在有限的"寿元"里，不断收集材料→合成道具→提升修为→对抗天劫→获得更多寿元，直至破碎虚空飞升成仙的故事。

### 1. 流年

- 游戏中的自然年。每过 1 自然年，玩家的年纪 +1
- 1 流年等同现实世界的：X 秒
- 随着寿元上限和道具交互 CD 增加，流逝率也增加
  - （如初始 1 年 = 60s，中期 10 年 = 60s，后期 100 年 = 60s）

### 2. 玩家寿元

- 开始新一局游戏时，固定初始寿元上限
- 提升境界可以增加寿元上限（主要）
  - 不同修炼途径增加寿元上限不叠加，以最高境界的寿元值为准
- 使用丹药、法宝也可适当增加寿元上限（次要）
  - 相同丹药加成值效果有衰退
- 特殊事件（如受伤、中毒）会降低寿元上限
- 玩家当前年纪达到寿元上限，此局游戏失败

### 3. 修炼（能力成长）

#### 3.1 主修路径

**法修（修真）**

- 路径定位：
  - 成长速度均衡稳定
  - 攻防参半，实力构成上限稳定，主要依赖法宝提供不同的能力
- 修为提升
  - 打坐练气
  - 丹药：增加修为类
- 境界提升
  - 需要修炼至当前境界的"圆满"状态
  - 丹药：服用对应境界的"突破丹"
  - 服用"突破丹"后，引动天劫。渡过天劫后提升至下一境界初期
  - 每个境界有附带的效果（技能、BUFF 等）
  - 使用子职业的约束条件
- 子职业依赖
  - 炼器：法宝（攻击类 / 防御类 / 功能类）
  - 炼丹：增加修为类 / 增加寿元类 / 境界突破类

**体修（炼体）**

- 路径定位：
  - 成长速度前快后慢
  - 防御高，主要依赖肉身
- 修为提升
  - 练功
  - 丹药：增加气血类
- 境界提升
  - 需要修炼至当前境界的"圆满"状态
  - 丹药：服用对应境界的"破境丹"
  - 服用"破境丹"后，引动天劫。渡过天劫后提升至下一境界初期
  - 每个境界有附带的效果（技能、BUFF 等）
  - 使用子职业的约束条件
- 子职业依赖
  - 炼器：护甲防具
  - 炼丹：增加修为类 / 增加寿元类 / 境界突破类

**剑修**

- 路径定位：
  - 成长速度前慢后快
  - 攻击高，主要依赖凝练剑丸中的剑气
- 修为提升
  - 凝练剑意
  - 战斗（扫怪）
- 境界提升
  - 需要修炼至当前境界的"圆满"状态
  - 丹药：服用对应境界的"剑意丹"
  - 服用"剑意丹"后，引动天劫。渡过天劫后提升至下一境界初期
  - 每个境界有附带的效果（技能、BUFF 等）
  - 使用子职业的约束条件
- 子职业依赖
  - 炼器：本命飞剑
  - 炼丹：增加寿元类 / 境界突破类

**魔修**

- 版本暂不开启：魔修路线与修真路线互斥，需要补充更复杂的逻辑
- 后续版本扩充内容时可以考虑

#### 3.2 子职业

**炼器**

- 职业等级
  - 职业有三个等级：炼器师、炼器宗师、神匠
  - 等级提升有升级条件，满足条件职业自动升级
  - 每个等级解锁对应等级可炼器的配方，分别对应器具的凡品、灵品、仙品
  - 炼器有境界要求，分别对应凡阶、圣阶、仙阶。以最高主职业的境界为准
  - 若不满足装备要求，则无法锻造
  - 如未修炼主职业剑修，则不可以炼制本命飞剑
- 类型
  - **法宝类**
    - 大部分由法修的"灵力"催动，不同法宝要求法修的不同境界
    - 法宝类无成长属性
    - 法宝品质：凡品 / 灵品 / 仙品
    - 法宝类型：进攻类 / 防御类 / 功能类 / 空间戒指（不分主职业，都可使用）
  - **护甲类**
    - 无需能量催动，不同的护甲要求体修的不同境界
    - 护甲类型：头 / 服装 / 盾、甲、铠
  - **飞剑类**
    - 由剑修剑丸中的剑气催动，本命飞剑可以通过"炼器"行为提升品质
    - 飞剑只能锻造凡品剑胚，当主职业境界和炼器职业满足时，可添加材料将飞剑升品
    - 飞剑品质：凡品 / 灵品 / 仙品
    - 飞剑类型：进攻类（设计 3~5 类初始飞剑特性，以及后续各成长路径）
  - **傀儡人**
    - 消耗"灵石"就可以自动采矿、种植草药等
    - 傀儡人不能战斗、不能装备、不能修炼功法
    - 初期版本简单设计，合并到炼器职业中
    - 只解决中期重复性采集类操作
  - **御兽索**
    - 消耗品，有几率将怪兽转化成灵宠
    - 初期版本简单设计，合并到炼器职业中
    - 只解决前-前中期补充伤害，丰富策略深度的体感
    - 道具品质：凡品 / 灵品
  - **符箓**
    - 消耗品，有一定增益效果
    - 初期版本简单设计，合并到炼器职业中
    - 动态调节数值平衡，丰富策略深度的体感
    - 道具类型：
      - 聚灵符：单位时间内，打坐额外增加 15% 修为值
      - 天机符：使用后遮蔽天机 10 年，当前年纪大于寿元上限也不会被天道发现，但实力降低 50%（有效时间随道具使用次数递减）
  - **阵法**
    - 有一定增益效果
    - 初期版本简单设计，合并到炼器职业中
    - 动态平衡后期剑修强度，丰富策略深度的体感
    - 道具类型：
      - 诛仙剑阵：以本命飞剑为阵眼，提升 100% 攻击力。获得稀有道具"诛仙阵图"后，需要分别炼诛、戮、绝、陷四剑，可组合成诛仙剑阵卡
      - 太极阵：将雷劫威力的 1/10，转化为自己的能量。获得稀有道具"太极阵图"后，需要分别炼阳鱼和阴鱼，可组合成太极阵卡

**炼丹**

- 职业等级
  - 职业有三个等级：丹师、大丹师、丹王
  - 等级提升有升级条件，满足条件职业自动升级
  - 每个等级解锁对应等级的丹方，分别对应丹药的凡品、灵品、仙品
  - 炼丹有境界要求，分别对应凡阶、圣阶、仙阶。以最高主职业的境界为准
  - 若不满足丹药使用要求，则无法炼该丹药
- 类型
  - 增加修为：法修、体修
  - 突破境界（不同阶段不同道具）：法修、体修、剑修
  - 增加寿元上限：通用，使用效果随次数衰减

**秘籍**

- 稀有道具：神秘商店/奇遇获得
- 秘籍只有"仙品"品质，满足特定主职业和境界可修炼
- 秘籍有不同的修炼方式：倒计时 / 完成特定条件
- 秘籍修炼完成后，可拥有一个强力技能/BUFF
- 初期版本简单设计，5-10 个秘籍
- 当前为了提供"中奖"感受，丰富策略深度的体感
- 后续有根据秘籍规划成长策略的潜力

### 4. 境界

- 境界提升提升本局游戏的寿元上限。三个主职业以最高的寿元上限为准，不叠加
- 境界提升后激活本职业技能、BUFF 等效果。该效果可叠加（如阳神身外化身、剑气化身等）
- 境界约束参与炼器、炼丹、秘籍、法宝、道具等的使用（需要满足该主职业最低境界要求才可）

### 5. 敌对

#### 5.1 天劫

- 各主职业提升境界的必要条件
- 各主职业凡阶各境界升境只需要必要丹药，不需要渡天劫（雷劫）
- 渡劫失败，本局游戏结束
- 渡劫成功但受伤，会根据受伤程度扣除寿元上限

#### 5.2 心魔

- 各主职业在不同境界触发心魔
- 心魔附带 Debuff
- 心魔不会自己消失，需要玩家主动将其消灭
- 心魔存在，则 Debuff 一直存在

| 主职业 | 心魔 |
|---|---|
| 法修 | 道幻心魔、化身心魔、长生虚妄心魔、神通贪执心魔、阴神心魔 |
| 体修 | 本能心魔、痛苦反噬心魔、血肉分身心魔、肉身执念心魔、恐惧心魔 |
| 剑修 | 杀业心魔、剑我之争心魔、剑化身心魔、偏执道心心魔、求败心魔 |

#### 5.3 怪物

- **灵兽**：击败怪物可获得该怪物的材料；可使用御兽索道具，将其转化成灵宠
- **妖兽 BOSS**：击败怪物可获得该怪物的材料
- **妖兽**：击败怪物可获得该怪物的材料

### 6. 道具

- **基础材料**
  - 品质：凡品 / 灵品 / 仙品
  - 类型：矿石类 / 药草类 / 妖兽残骸类 / 能量精华类
- **配方**
  - 炼器
  - 炼丹
